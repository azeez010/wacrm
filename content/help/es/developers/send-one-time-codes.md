OgaDesk puede entregar códigos de un solo uso por WhatsApp mediante una plantilla de autenticación aprobada.

## Qué necesitas
- Un número de WhatsApp conectado.
- Una plantilla de autenticación aprobada.
- Una clave de API.

Tu aplicación solicita un código, OgaDesk lo envía al WhatsApp del cliente y tu aplicación comprueba el código que el cliente escribe. Consulta la documentación de la API para ver las llamadas exactas.
