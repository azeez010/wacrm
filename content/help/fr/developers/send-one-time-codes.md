OgaDesk peut envoyer des codes à usage unique par WhatsApp grâce à un modèle d'authentification approuvé.

## Ce qu'il vous faut
- Un numéro WhatsApp connecté.
- Un modèle d'authentification approuvé.
- Une clé d'API.

Votre application demande un code, OgaDesk l'envoie sur le WhatsApp du client, puis votre application vérifie le code saisi par le client. Consultez la documentation de l'API pour les appels exacts.
