OgaDesk स्वीकृत ऑथेंटिकेशन टेम्पलेट के ज़रिए WhatsApp पर वन-टाइम कोड भेज सकता है।

## आपको क्या चाहिए
- जुड़ा हुआ WhatsApp नंबर।
- स्वीकृत ऑथेंटिकेशन टेम्पलेट।
- एक API कुंजी।

आपका एप्लिकेशन कोड माँगता है, OgaDesk उसे ग्राहक के WhatsApp पर भेजता है, और ग्राहक द्वारा दर्ज किया गया कोड आपका एप्लिकेशन जाँचता है। सटीक कॉल के लिए API डॉक्स देखें।
