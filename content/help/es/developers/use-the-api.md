La API REST permite que tus sistemas creen contactos, lean conversaciones y envíen mensajes.

## Obtén una clave
1. Abre **Ajustes → Claves de API**.
2. Crea una clave y cópiala. Se muestra una sola vez, así que guárdala bien.
3. Envíala en cada solicitud como se describe en la documentación de la API.

## Más información
La referencia completa, con ejemplos de cada endpoint, está en la página de documentación de la API enlazada en el pie del sitio.

Mantén tus claves en secreto y cámbialas si crees que una se ha filtrado.
