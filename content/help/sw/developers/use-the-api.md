API ya REST huruhusu mifumo yako kuunda anwani, kusoma mazungumzo, na kutuma jumbe.

## Pata ufunguo
1. Fungua **Mipangilio → Funguo za API**.
2. Tengeneza ufunguo na uunakili. Huonyeshwa mara moja tu, kwa hivyo uhifadhi mahali salama.
3. Utume kwa kila ombi kama ilivyoelezwa kwenye nyaraka za API.

## Jifunze zaidi
Marejeleo kamili, pamoja na mifano kwa kila endpoint, yako kwenye ukurasa wa nyaraka za API uliounganishwa chini ya tovuti.

Weka funguo zako siri na uzibadilishe ukidhani mojawapo imevuja.
