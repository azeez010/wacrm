A API REST permite que seus sistemas criem contatos, leiam conversas e enviem mensagens.

## Obtenha uma chave
1. Abra **Configurações → Chaves de API**.
2. Crie uma chave e copie-a. Ela aparece uma única vez, então guarde-a com segurança.
3. Envie-a em cada requisição, como descrito na documentação da API.

## Saiba mais
A referência completa, com exemplos de cada endpoint, está na página de documentação da API, linkada no rodapé do site.

Mantenha as chaves em segredo e troque-as se achar que alguma vazou.
