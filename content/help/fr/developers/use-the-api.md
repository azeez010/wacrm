L'API REST permet à vos systèmes de créer des contacts, de lire des conversations et d'envoyer des messages.

## Obtenir une clé
1. Ouvrez **Paramètres → Clés d'API**.
2. Créez une clé et copiez-la. Elle ne s'affiche qu'une fois : conservez-la en lieu sûr.
3. Envoyez-la avec chaque requête, comme décrit dans la documentation de l'API.

## En savoir plus
La référence complète, avec des exemples pour chaque point d'accès, se trouve sur la page de documentation de l'API, liée dans le pied de page du site.

Gardez vos clés secrètes et renouvelez-les si vous pensez qu'une clé a fuité.
