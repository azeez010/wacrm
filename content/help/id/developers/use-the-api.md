API REST memungkinkan sistem Anda membuat kontak, membaca percakapan, dan mengirim pesan.

## Dapatkan kunci
1. Buka **Pengaturan → Kunci API**.
2. Buat kunci dan salin. Kunci hanya ditampilkan sekali, jadi simpan dengan aman.
3. Kirim kunci pada setiap permintaan seperti dijelaskan di dokumentasi API.

## Pelajari lebih lanjut
Referensi lengkap beserta contoh untuk tiap endpoint ada di halaman dokumentasi API yang ditautkan di footer situs.

Jaga kerahasiaan kunci dan ganti jika Anda curiga ada yang bocor.
