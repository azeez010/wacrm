title: Utiliser la boîte de réception partagée
summary: Répondez, attribuez et suivez chaque conversation.
order: 1
---
La **boîte de réception** affiche toutes les conversations WhatsApp, les plus récentes en premier.

## Répondre plus vite
- Utilisez les **réponses rapides** pour les messages que vous envoyez souvent.
- Ajoutez des notes internes pour que vos collègues voient le contexte sans que le client le voie.

## Rester organisé
- Attribuez une conversation à un collègue pour que chacun sache qui s'en occupe.
- Fermez les conversations résolues ; elles se rouvrent si le client écrit à nouveau.

## Ne manquez aucun message
Activez le son de nouveau message et les notifications du navigateur dans **Paramètres** ; le nombre de messages non lus s'affiche aussi dans l'onglet.
