REST API로 시스템에서 연락처를 만들고, 대화를 읽고, 메시지를 보낼 수 있습니다.

## 키 발급
1. **설정 → API 키**를 엽니다.
2. 키를 만들고 복사합니다. 한 번만 표시되므로 안전하게 보관하세요.
3. API 문서에 설명된 대로 모든 요청에 키를 포함합니다.

## 더 알아보기
엔드포인트별 예시가 담긴 전체 레퍼런스는 사이트 하단에 링크된 API 문서 페이지에 있습니다.

키는 비밀로 유지하고, 유출이 의심되면 교체하세요.
