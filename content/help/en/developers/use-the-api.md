The REST API lets your systems create contacts, read conversations and send messages.

## Get a key
1. Open **Settings → API keys**.
2. Create a key and copy it. It is shown once, so store it safely.
3. Send it with every request as described in the API docs.

## Learn more
The full reference, with examples for each endpoint, is on the API docs page linked in the site footer.

Keep keys secret and rotate them if you think one has leaked.
