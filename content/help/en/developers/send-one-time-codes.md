OgaDesk can deliver one-time codes through WhatsApp using an approved authentication template.

## What you need
- A connected WhatsApp number.
- An approved authentication template.
- An API key.

Your application requests a code, OgaDesk sends it to the customer's WhatsApp, and your application checks the code the customer types back. See the API docs for the exact calls.
