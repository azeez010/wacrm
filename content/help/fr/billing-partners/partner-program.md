Toute personne ayant un compte OgaDesk est automatiquement partenaire.

## Comment ça marche
1. Ouvrez **Programme partenaire** dans la barre latérale pour trouver votre lien personnel.
2. Partagez-le avec des entreprises qui vendent ou assurent leur support client sur WhatsApp.
3. Suivez les clics, les inscriptions et les clients dans vos statistiques.

## Ce que vous gagnez
Les partenaires touchent un pourcentage des paiements éligibles pendant un certain nombre de mois. Le taux actuel et le simulateur de gains se trouvent sur la page publique des partenaires.

## Bon à savoir
- Votre premier code de parrainage compte : une personne ne peut être parrainée qu'une fois.
- Vous ne pouvez pas vous parrainer vous-même.
- Les paiements ouvriront avec les offres payantes ; le suivi démarre dès maintenant.
