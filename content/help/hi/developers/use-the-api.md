REST API से आपके सिस्टम संपर्क बना सकते हैं, बातचीत पढ़ सकते हैं और संदेश भेज सकते हैं।

## कुंजी पाएँ
1. **सेटिंग्स → API कुंजियाँ** खोलें।
2. कुंजी बनाएँ और कॉपी करें। यह सिर्फ़ एक बार दिखती है, इसलिए इसे सुरक्षित रखें।
3. API डॉक्स में बताए अनुसार हर अनुरोध के साथ इसे भेजें।

## और जानें
हर एंडपॉइंट के उदाहरणों वाला पूरा संदर्भ साइट के फ़ुटर में दिए API डॉक्स पेज पर है।

कुंजियाँ गोपनीय रखें और लीक होने का शक हो तो बदल दें।
