O OgaDesk pode entregar códigos de uso único pelo WhatsApp usando um modelo de autenticação aprovado.

## O que você precisa
- Um número de WhatsApp conectado.
- Um modelo de autenticação aprovado.
- Uma chave de API.

Seu aplicativo solicita um código, o OgaDesk o envia ao WhatsApp do cliente e seu aplicativo confere o código digitado pelo cliente. Veja na documentação da API as chamadas exatas.
